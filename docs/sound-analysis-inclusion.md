# Selected sound estimates for new nights

Sound sensitivity → Detected categories has independent switches for Snoring, Speech, Cough/throat clear, Baby crying, Laughter and Other sounds. At least one must remain on. Save applies to the next admitted night; an existing immutable ClipBudget snapshot is reused through microphone restarts and sonar pause/resume. Saving does not create a capture/model, request permission, enable cues or change sound/clip consent.

The unchanged classifier chooses its original winning estimate using the same scores and margins. Grouping drops an excluded winner before event accumulation, flushes the previous group and never chooses a runner-up or converts that class into Other. Other independently controls only actual noise-category results. Selected classes retain their existing duration policy. Disabling Snoring therefore creates no new snoring event and never invokes or spends the snoring cue budget. This is a selection control, not improved recognition accuracy. The independent laughter-positive gate remains unchanged and failing.

Movement recording previously saved amplitude-triggered ambient10-second WAVs independently of labels. Those files cannot truthfully be described as class-specific. Therefore **any custom category selection disables every new clip for that night**, even when the existing clip consent is on. Both clip admission and the recorder's archive path enforce this immutable rule. The saved global clip preference and all previous files remain unchanged; re-enabling all classes for a future night restores its existing clip behavior. The native settings explain this; the live recording shows Analysis only and the custom-selection reason. Room-level noise measurements still use the consented microphone, and an included estimate can still be mistaken. This does not claim reliable exclusion of an actual acoustic source from model labels.

Shared sonar uses the identical filtered Group through its existing single48kHz capture→16kHz inference fanout; it still saves no WAVs. Speak challenge acceptance is independent and unchanged.

Private `sound_detection_v1/profile` JSON now writes strict version2 with six explicit boolean selection keys. Version1 and an absent profile mean every class enabled with identical original durations. Unknown/missing/malformed selection keys, nonboolean values, unsupported versions and empty selection are rejected; The settings screen shows default choices with an explicit error; the runtime snapshot is blocked until a valid profile is explicitly saved/reset. Unreadable existing profiles and storage failures cannot silently restore clips or model analysis. Genuine absence and valid version1 alone retain exact legacy defaults. Movement noise capture exits before microphone/model allocation; shared sonar keeps its separate movement capture and persists an existing capture-error status without an analysis worker/model. Existing private duration fields are preserved. Per-device analysis settings remain excluded from portable global preferences, as before; no backup format/schema contract was widened. Existing raw scores/category/model/timing, user label overlays, night metadata and original WAV bytes are not edited by this control.
