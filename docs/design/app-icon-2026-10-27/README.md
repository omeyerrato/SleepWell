# SleepWell launcher icon

Original code-native mark: lavender crescent embracing a warm dawn clock on the app’s plum background. The original green square launcher tile is replaced with separate Android adaptive background/foreground layers, a round launcher resource and an Android13+ monochrome layer. All mark geometry stays inside the adaptive safe region. No generated bitmap, external logo/font or launcher-data reset is required.

The editable SVG mirrors the Android vector geometry with a preview mask; Android applies the actual launcher mask/parallax. The SVG/PNG preview is a design render, not an Android screenshot. Native resources in app/src/main/res are the shipped assets. Existing notification small-icon resources remain separate.
