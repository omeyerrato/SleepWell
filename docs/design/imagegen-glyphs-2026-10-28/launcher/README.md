# SleepWell folded-quilt identity

Built-in imagegen generated this original flat folded-quilt S and morning sun.
The earlier glossy crescent was rejected by the user and is not packaged. The
[color original](sleepwell_launcher_flat.png), generated monochrome mask, exact
prompts and [hash mapping](mapping.json) are retained here.

Android adaptive icons use the color raster as their background and a native
transparent foreground. The raster monochrome mask has a 14dp inset to fit the
adaptive safe area. The same generated mask replaces the old opaque notification
vector. Density derivatives are ordinary resizes; no paths were redrawn.

Launcher appearance on a real Android launcher and themed-mask fidelity still
require Android inspection. The user has seen the generated color artwork;
this does not imply acceptance of the rejected earlier icon or all app screens.
